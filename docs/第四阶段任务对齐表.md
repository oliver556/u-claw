## 1. 统计规则

```text
第四阶段完成度 = 状态为“已完成”的 Task 数 / 9
```

- Task 内任一矩阵行仍是 `未接线`、`已接线待联调` 或存在 Critical/Important 缺陷，Task 不计完成。
- `本地真实通过` 要求真实 OpenClaw/runtime/文件系统，不接受 Mock 或 scripted socket。
- `待外部环境` 只能用于确实依赖外部账号、Windows、物理 U 盘或远程服务的项目。
- 完成 Task 后同步更新本表和联调矩阵，禁止只更新其中一份。

## 4. 执行顺序

```text
P4-T00
-> P4-T01
-> P4-T02 / P4-T03 / P4-T04 / P4-T05
-> P4-T06 / P4-T07
-> P4-T08
-> P3-T08
```

- `P4-T02`–`P4-T05` 在 `P4-T01` 契约稳定后可并行。
- `P4-T06` 依赖真实会话与任务链。
