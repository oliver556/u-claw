## 1. 状态定义

| 状态 | 定义 |
| --- | --- |
| `未接线` | UI 仍是 Mock、固定数据、空数组、`Unsupported`，或尚无 UI |
| `已接线待联调` | 生产调用链存在，但没有真实成功证据 |
| `本地真实通过` | 真实本地 OpenClaw/Gateway/文件/本地服务成功和失败路径通过 |
| `待外部环境` | 仅缺真实账号、Windows、物理 U 盘或远程服务 |
| `已验收` | 指定正式环境的成功、失败、重启和读回证据完整 |
| `不迁移` | 已批准的内部能力，附明确理由和替代路径 |

每行完成时补充：环境、实际请求/事件、成功证据、失败证据、代码提交和验收人。
