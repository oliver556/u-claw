# 对话队列与多模态附件实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现运行中多模态引导、持久队列、图片/视频粘贴预览，以及可靠的会话右键菜单和重命名。

**Architecture:** Shared 定义队列和流式附件契约；Desktop 在 U 盘数据目录维护权威队列与附件缓存；Adapter 复用 OpenClaw `chat.send` 发送完整多模态消息；React 只管理可编辑视图状态。队列发送和清理均在主进程串行化，防止双发与误删。

**Tech Stack:** TypeScript、Electron、React、Zod、OpenClaw Gateway RPC、Vitest、Testing Library
