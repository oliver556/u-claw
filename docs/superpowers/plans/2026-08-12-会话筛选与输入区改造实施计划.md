# 会话筛选与输入区改造实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成分组筛选、工作区去侧栏、输入框底栏重排，并让单次 Skill 选择真实调用 OpenClaw。

**Architecture:** Renderer 负责筛选和一次性选择状态；Shared 契约传递 `skillId`；Adapter 通过 OpenClaw `commands.list` 权威解析 Skill 命令并在 `chat.send` 前转换。现有 ContextPanel、模型服务、附件服务和 Skill 管理服务保留。

**Tech Stack:** React 19、Ant Design、TypeScript、Zod、Electron、Vitest、Playwright。
