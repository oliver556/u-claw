# Bavi-box 首版功能隐藏实施计划

> **执行要求：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` skill 逐任务执行。使用复选框 `- [ ]` 跟踪进度。

**目标：** 在首个对外发布版本中隐藏未纳入发布范围的导航、渠道、系统页签、全局搜索和模型状态，保留已实现代码和后端能力。

**架构：** 新增一个前端首版产品表面配置，集中定义可见主导航、系统页签、渠道类型和顶栏控件。组件只渲染配置允许的产品表面，不删除 route、IPC schema、Desktop service 或底层数据。

**技术栈：** TypeScript 5.9、React 19、React Router 7、Vitest、Testing Library、Playwright。

---

## 范围冻结

### 首版显示

- 主导航：`工作`、`能力`、`连接`、`用量`、`余额`、`系统`。
- 连接：`个人微信`。
- 系统页签：`发布更新`、`外观`。
- 顶栏：U 盘状态、Gateway 状态、任务活动中心、窗口控件。

### 首版隐藏

- 主导航：`文件`、`记忆`、`自动化`。
- 连接：`Telegram`、`QQ Bot`、`飞书`、`企业微信`、`Discord`，以及渠道筛选、新增入口和非个人微信卡片。
- 系统页签：`诊断`、`设备与运行`、`语音与通知`、`产品授权`、`备份与存储`。
- 顶栏：全局搜索按钮、对话框、`Ctrl K` 监听和模型状态。

`用量`和 `余额` 不在本次明确隐藏清单内，因此继续显示。本计划不扩大用户指定的隐藏范围。
