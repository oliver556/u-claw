# Task 9B 便携运行时启动器实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于 Task 9A 选定的 Go，实现可校验 `runtime.pkg`、原子准备本机缓存、固定 U 盘数据目录并启动 Electron 的 Windows x64 正式 Launcher。

**Architecture:** `product/launcher` 只负责启动与监督，不包含业务 UI 或 OpenClaw 协议。`runtime.pkg` 固定为 gzip 压缩 tar；Node 构建脚本生成包和严格 `version.json`，Go Launcher 流式校验并解压到 `%LOCALAPPDATA%/U-Claw/runtime/<runtime-id>`。所有用户数据路径从 U 盘 `.uclaw/data` 注入，缓存仅保存可重建 runtime。

**Tech Stack:** Go 1.25、Go 标准库 `archive/tar`/`compress/gzip`、Node.js 24.15.0、`tar` npm 包、Node test runner、PowerShell 5.1/7、GitHub Actions Windows Runner。正式 Launcher 使用 Go 1.25+，因为安全缓存依赖 `os.Root.MkdirAll`、`os.Root.RemoveAll` 和 `os.Root.Rename`；Task 9A 的 Go 1.24.4 仅作为语言选型基准。

---

## 决策与边界

- Task 9A `decision.json`：`selected=go`、`reason=p95-margin`。
- Go P95 `21.7459ms`，NativeAOT P95 `29.9361ms`；两者 mandatory gate 均通过。
- `runtime.pkg` 不允许链接、设备文件、绝对路径、`..`、Windows 保留名和重复条目。
- `version.json` 严格字段：`schemaVersion`、`productVersion`、`runtimeVersion`、`runtimeId`、`runtimeArchive`、`runtimeSha256`、`runtimeBytes`、`unpackedBytes`、`fileCount`、`entrypoint`、`entryArgs`。
- `entrypoint` 必须是 runtime 内安全相对路径；`entryArgs` 直接传递给 `exec.Command`，禁止 shell 拼接。
- 本任务不实现第三阶段许可证，不虚标真实 Win10/11 U 盘验收。
