# 第五阶段 Skill 本地管理与受控安装 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 `P5-T08`：本地 Skill 工作台、SkillHub 受控外跳、ZIP 安全导入和聊天安装提示词闭环。

**Architecture:** 共享层只负责严格 IPC 契约和纯安装意图解析。Desktop 持有文件选择、下载、暂存、校验、安装和外链白名单等权限；Renderer 只提交结构化身份或不可伪造的选择结果，并复用现有 `SkillService` 事务及 OpenClaw 读回。

**Tech Stack:** TypeScript、Zod、Electron IPC、React 19、Vitest、Testing Library、现有 `SkillService` 与 bundle validator。

### Task 1: 安装意图解析与共享契约

- [ ] **Step 1: 写失败测试**

在 `product/shared/tests/skill-install-intent.test.ts` 覆盖：官方 `skillhub.md` 提示词返回唯一 `@namespace/skill`；普通聊天、多个身份、伪造 host、身份缺失、含 shell 拼接符的文本返回 `null`。在 `product/shared/tests/capabilities.test.ts` 验证新增请求拒绝未知字段、绝对路径和非白名单 URL。

- [ ] **Step 2: 验证 RED**

Run: `npm test -w @uclaw/shared -- skill-install-intent.test.ts capabilities.test.ts`

Expected: FAIL，原因为解析器或新 IPC method 尚不存在。

- [ ] **Step 3: 最小实现**

实现：

```ts
export type SkillInstallIntent = {
  provider: "skillhub";
  identity: `@${string}/${string}`;
  source: "official-prompt";
};

export function parseSkillInstallIntent(text: string): SkillInstallIntent | null;
```

只接受精确 `https://skillhub.cn/install/skillhub.md`、唯一身份和无 shell 控制字符的文本。新增 strict discriminated union 方法，Renderer 不得提交绝对文件路径或任意 URL。

- [ ] **Step 4: 验证 GREEN**

Run: `npm test -w @uclaw/shared -- skill-install-intent.test.ts capabilities.test.ts && npm run typecheck -w @uclaw/shared`

Expected: PASS。

### Task 2: Desktop 受控 ZIP 导入和安装协调

- [ ] **Step 1: 写失败测试**

测试选择取消、非 ZIP、超过 `20 * 1024 * 1024`、选择令牌过期、重复消费、校验失败清理暂存，以及成功候选不暴露绝对路径。复用现有 bundle validator 的路径穿越、大小写冲突、Win32 设备名、ADS、ancestor conflict 与 canonical `SKILL.md` 用例。

- [ ] **Step 2: 验证 RED**

Run: `npm test -w @uclaw/desktop -- skill-import-service.test.ts`

Expected: FAIL，原因为 `SkillImportService` 尚不存在。

- [ ] **Step 3: 最小实现**

`SkillImportService.select()` 只调用 Desktop 注入的文件选择器，复制到 Desktop 暂存目录并返回 opaque token 与展示元数据；`prepare(token)` 单次消费、复查大小并调用 bundle validator；`dispose(token)` 删除暂存。`SkillInstallCoordinator` 将准备结果转成现有 `SkillService.startInstall` 所需输入，不新建第二套 replace/rollback 逻辑。

- [ ] **Step 4: 接入 IPC 与白名单外跳**

新增 `skills.import-select`、`skills.import-prepare`、`skills.import-dispose`、`skills.open-hub`。`skills.open-hub` 内部固定打开 `https://skillhub.cloud.tencent.com/skills`，不接受 Renderer URL。

- [ ] **Step 5: 验证 GREEN**

Run: `npm test -w @uclaw/desktop -- skill-import-service.test.ts skill-service.test.ts && npm run typecheck -w @uclaw/desktop`

Expected: PASS，失败路径无残留暂存文件。
