# 对话图片预览与系统操作 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为对话图片提供全屏预览、缩放平移、右键复制和另存能力，并把所有系统权限封装在 Electron 主进程。

**Architecture:** Shared 定义受控图片 URL 与独立 IPC 契约；preload 只暴露 `images.invoke()`；Electron 图片服务鉴权拉取、校验、复制或原子保存；React 组件只管理预览和菜单状态。前端和主进程在共享契约完成后并行开发，最后统一接线和真实验收。

**Tech Stack:** TypeScript、React、Electron、Zod、Vitest、Testing Library、Lucide React。
