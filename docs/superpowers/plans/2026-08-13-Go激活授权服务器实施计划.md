# Go 激活授权服务器实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `product/activation-server` 交付可独立部署的 Linux x64 Go 授权服务，完成库存、首次绑定、幂等恢复、许可证生命周期和管理员 CLI。

**Architecture:** 新 Go module 使用标准库 HTTP、PostgreSQL 和 Ed25519。`api/openapi.yaml` 是 HTTP 契约源；业务状态由 PostgreSQL 事务和唯一约束保证；可恢复授权材料经 KMS adapter 信封加密。

**Tech Stack:** Go 1.25、PostgreSQL、pgx/v5、OpenAPI 3.1、Ed25519、Docker、Vitest contract tests

---

## 文件结构

```text
product/activation-server/
  api/openapi.yaml                 HTTP 契约
  cmd/server/main.go               服务入口
  cmd/admin/main.go                管理 CLI
  internal/activation/service.go   激活状态机

  internal/inventory/code.go       激活码生成/摘要

  internal/persistence/postgres.go DB 与事务边界
  internal/persistence/migrations.go
  internal/transport/http.go       公开/管理 handler
  internal/security/envelope.go    KMS adapter
  migrations/001_initial.sql
  Dockerfile
```
