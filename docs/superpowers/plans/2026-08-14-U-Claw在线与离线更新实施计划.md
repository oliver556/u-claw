# U-Claw 在线与离线更新 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 `updates.yiyong.me` 手动在线更新和单文件离线更新器，两条链路共用现有 Launcher 验签、防降级、事务和回滚内核。

**Architecture:** Electron 只负责在线检查、确认和进度；Launcher `--release-fs-helper` 是唯一有权切换 U 盘 runtime 的组件。离线更新器内嵌与线上字节一致的清单和 `runtime.pkg`，发现目标 U 盘后流式传入目标 Launcher helper，不复制安装逻辑。

**Tech Stack:** Go 1.25, Node.js 24, TypeScript 5.9, Electron 40, React 19, Vitest, Node test runner, PowerShell 5.1/7, Nginx.
