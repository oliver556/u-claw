# U-Claw 在线与离线更新实施计划

> **执行要求：** 必须使用 `subagent-driven-development`（推荐）或 `executing-plans` skill 逐任务执行。使用复选框 `- [ ]` 跟踪进度。

**目标：** 交付 `updates.yiyong.me` 手动在线更新和单文件离线更新器，两条链路共用现有 Launcher 验签、防降级、事务和回滚内核。

**架构：** Electron 只负责在线检查、确认和进度；Launcher `--release-fs-helper` 是唯一有权切换 U 盘 runtime 的组件。离线更新器内嵌与线上字节一致的清单和 `runtime.pkg`，发现目标 U 盘后流式传入目标 Launcher helper，不复制安装逻辑。

**技术栈：** Go 1.25、Node.js 24、TypeScript 5.9、Electron 40、React 19、Vitest、Node 测试运行器、PowerShell 5.1/7、Nginx。

---

const updateRestartExitCode = 42
type exitCoder interface { ExitCode() int }
func isUpdateRestartExit(err error) bool {
	var coded exitCoder
	return errors.As(err, &coded) && coded.ExitCode() == updateRestartExitCode
}
