# 激活服务部署与验收计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Go 授权服务安全部署到 Linux x64，并用正式 HTTPS、PostgreSQL、密钥、备份和 Windows 物理 U 盘证明可发布。

**Architecture:** 公网网关承担 TLS/WAF/限流，至少两个无状态 Go 实例访问托管 PostgreSQL 和 KMS。更新元数据可共用控制面，但更新包、数据库和签名信任根隔离。

**Tech Stack:** Linux amd64、Docker、PostgreSQL、KMS、对象存储/CDN、Windows 10/11 E2E
