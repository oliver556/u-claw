# 单客户端启动激活实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将激活流程接入现有 Go Launcher 和唯一 Electron 客户端，未激活只开放受限 UI/IPC，成功后退出并由 Launcher 重跑完整 gate。

**Architecture:** Launcher 先分类授权材料，再准备受信 runtime，以显式 `activation-only` 参数启动现有 Electron 包。Electron main process 在该模式下不启动 Gateway/OpenClaw，只注册激活 IPC；写盘验签完成后用退出码通知 Launcher 重跑。

**Tech Stack:** Go 1.25、Electron 40、TypeScript 5.9、React 19、Zod、Vitest、Playwright
