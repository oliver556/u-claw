# 对话队列与多模态附件设计

## 目标

让运行中的会话继续接收输入，同时完善会话菜单和多模态附件体验：

- `Enter` 把当前“文字 + 附件”立即用于调整当前任务方向。
- macOS `Command+Enter`、Windows/Linux `Ctrl+Enter` 把完整消息加入队列。
- 队列按会话持久化到 U 盘；刷新、切换会话、重启客户端后仍存在。
- 图片、视频支持粘贴、拖入、选择，并在输入框顶部预览。
- 会话整行可右键；重命名使用应用内弹窗。

## 交互设计

### 运行中输入

输入框在模型运行期间保持可编辑。发送按钮仍显示停止图标，不影响键盘提交：

- `Enter`：若当前会话有活动任务，立即发送完整多模态消息，作为调整方向；空闲时等同普通发送。
- `Command/Ctrl+Enter`：加入当前会话队列。
- `Shift+Enter`：换行。

队列项显示在输入框上方的独立横条。每项包含摘要和三个操作：

- “调整方向”：整项立即发送，文字与附件不可拆分。
- 删除：删除整项并解除附件引用。
- `…`：只提供“编辑消息”；允许编辑文字、替换或删除附件。

当前任务正常结束后，自动发送该会话第一条可发送队列项。失败项保留并显示错误，不阻塞用户编辑、删除或重试。

### 附件预览

附件区位于输入框内部顶部：

- 图片：缩略图。
- 视频：首帧、播放标识和时长。
- 普通文件：文件类型、名称和大小。
- 每项右上角提供删除按钮。

支持剪贴板粘贴、拖入和文件选择。粘贴时优先读取剪贴板文件；没有文件时保留普通文本粘贴行为。

## 技术设计

### 消息队列

新增共享队列契约和 Desktop 权威存储。Renderer 不使用 `localStorage` 作为权威来源。

队列文档按会话保存以下字段：

- 队列项 ID、会话 ID、文字、附件引用、模型和 Skill 选择。
- 创建、更新时间、发送状态、失败摘要和稳定幂等键。
- 附件引用指向 U 盘受控附件缓存，不内嵌 Base64。

写入采用现有 Desktop JSON store 的串行原子替换模式。队列取首项、标记发送、成功删除均由主进程串行化，防止双发。

### 调整方向与自动发送

复用 OpenClaw 原生控制台语义：运行中再次调用 `chat.send`，携带完整附件和稳定幂等键。不得用仅支持文字的 `sessions.steer` 代替。

普通发送、调整方向、队列自动发送共用同一条 Adapter `chat.send` 路径：

1. 从受控缓存解析附件。
2. 发送文字及附件。
3. 消费流式结果。
4. 终态成功后确认队列项并解除引用。
5. 终态失败时保留队列项和幂等键，允许安全重试。

### 多模态附件

扩展现有附件服务：

- 图片：PNG、JPEG、GIF、WebP。
- 视频：MP4、MOV、WebM，单文件上限 500 MB。
- 现有文件：PDF、TXT。

小文件可继续走现有内存路径；视频必须流式写入 U 盘受控缓存，禁止把 500 MB 内容编码为 Renderer IPC Base64。Renderer 通过受控文件选择、拖放或剪贴板 File 交给主进程分块导入。

Adapter 按 OpenClaw `chat.send.attachments` 契约把视频映射为 `type: file`、真实 `video/*` MIME 和受控内容来源，实际模型链路使用已配置的多模态 Provider。

### 缓存与清理

- 附件和必要中间产物位于 U 盘数据目录的受控缓存。
- 视频及中间产物在最后一次发送或引用解除后保留 24 小时。
- 被草稿或队列引用的文件不得清理。
- 启动时及固定周期清理过期且无引用文件。
- 导入前检查单文件 500 MB 上限、附件总量和 U 盘剩余空间。
- 预览使用受控 IPC/协议读取，不向 Renderer 暴露任意本地路径。

### 会话菜单与重命名

- 会话整行监听 `contextmenu`，打开与三点按钮相同的菜单。
- 左键整行仍只选择会话。
- 菜单关闭规则覆盖点击外部、`Escape`、选择操作和切换会话。
- 重命名使用应用内 Modal + Input；提交后调用现有 `client.sessions.rename`，读取权威会话结果并刷新列表。
- 重命名失败保留弹窗和输入内容，并显示后端错误。

## 错误处理

- 不支持的 MIME、超限、空间不足：导入前显示明确错误，不创建半成品队列项。
- 附件丢失或校验失败：队列项标记失败，不发送残缺消息。
- Gateway 离线：队列保留，恢复连接后再发送。
- 调整方向发送失败：恢复原队列项，不丢文字、附件和幂等键。
- 重命名失败：不乐观篡改标题。

## 验收

- 运行中可输入；`Enter` 调整方向，`Command/Ctrl+Enter` 入队，`Shift+Enter` 换行。
- 队列自动发送，发送前可编辑或删除，并跨刷新、切换会话、重启保留。
- 文字和附件始终作为同一消息发送。
- 图片/视频可粘贴并预览；视频真实进入 OpenClaw 多模态链路。
- 视频上限 500 MB，缓存 24 小时后清理；活跃引用不清理。
- 会话整行右键打开菜单；重命名真实成功且刷新后保留。
