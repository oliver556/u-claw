# 会话栏与任务活动中心收口设计

## 范围

- 只修改工作区第二列会话栏；不修改 `PrimaryRail`、应用标题栏和聊天区。
- 会话栏标题为“会话”，标题右侧依次放新对话、搜索、任务活动中心按钮。
- 内容区提供“最近 / 分组”两种视图；搜索展开为独立状态。
- 会话行仅常驻内容，固定、移组、重命名、删除统一放入更多菜单。
- 任务活动中心只保留 `TaskArtifactCenter` 和专用 preload bridge。

## 会话栏交互

- 最近：按“固定 / 今天 / 更早”展示。
- 分组：先展示“我的分组”，选择后只展示该分组会话，并提供新建、重命名、删除分组。
- 搜索：点击标题搜索按钮展开输入框；关闭后恢复之前的最近或分组视图。
- 铃铛：打开唯一任务活动中心。

## 任务中心数据

- Gateway 支持 `tasks.* / artifacts.*` 时，使用真实权威 RPC。
- 不支持时，从同一个 OpenClaw Gateway 的会话、消息、运行、审批和文件事实构建只读快照。
- fallback 只允许读取；取消、重试、下载、打开、导出必须 fail closed，不伪造成功。
- 删除未使用的 `TaskActivityCenter` 重复实现及其测试入口。

## 验收

- 会话栏三枚标题按钮、两种视图、搜索状态和更多菜单均可操作。
- 铃铛打开唯一 `TaskArtifactCenter`。
- 原生 Task/Artifact RPC 优先；旧 Gateway 能展示聚合数据，写操作明确不可用。
- 受影响 frontend/desktop typecheck 与定向测试通过。
