# 会话筛选与输入区改造设计

## 目标

让工作页更接近原生 AI 客户端：会话分组可筛选；对话内容区减少固定信息；模型、附件、Skill 集中在输入框底栏；Skill 选择真实到达 OpenClaw。

## 交互

- 分组标签可点击。点击后只显示该分组会话；再次点击恢复全部。
- 搜索在当前分组范围内执行。当前分组为空时显示明确空状态。
- 已固定会话也受当前分组筛选，不跨组泄漏。
- 对话顶部整条隐藏，不展示标题、模型说明、自动保存、模型选择和归档。
- 右侧上下文舱默认完全隐藏，不占栅格宽度，也不显示恢复入口；底层能力保留。
- 输入框底栏从左到右提供附件、模型、Skill；右侧保留发送/停止。
- Skill 单选，仅列已安装、已启用、可用且允许用户调用的 Skill。
- Skill 仅作用于下一条消息。发送成功后清空；发送失败或中止时保留。

## 真实接线

`SendMessageInput` 增加可选 `skillId`。Renderer 发送用户选择的 Skill ID。Adapter 不信任前端提供的命令文本，而是读取 OpenClaw `commands.list`，在 `source=skill` 的权威命令中解析对应 Skill，再把调用转换为 OpenClaw 支持的斜杠命令消息。解析不到、不可用或不唯一时 fail closed，不发送普通消息冒充 Skill 调用。

外部 OpenAI-compatible Provider 不支持 OpenClaw Skill，选择 Skill 时必须返回 `UNSUPPORTED`，不能静默忽略。

## 状态与错误

- 模型或 Skill 目录加载失败时，底栏对应选择器显示错误态，其余输入能力可继续使用。
- Skill 在选择后、发送前失效时，Adapter 返回明确错误；输入内容和 Skill 选择都保留。
- 分组筛选只影响展示，不修改会话归属和持久化数据。

## 验收

- 组件测试覆盖分组选择、取消、组内搜索和固定会话隔离。
- 契约、Adapter 测试覆盖 Skill ID 校验、权威命令解析、真实请求映射及 fail closed。
- Electron E2E 覆盖右栏隐藏、顶部隐藏、底栏控件和分组筛选。
- 明暗主题与 960px 最小窗口无重叠、截断或布局跳动。
