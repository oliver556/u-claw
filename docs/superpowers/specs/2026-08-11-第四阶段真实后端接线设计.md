# U-Claw 第四阶段真实后端接线设计

> 记录日期：2026-08-11  
> 目标：把第一、二、三阶段已完成的 UI、契约、Store 和本地服务接到真实 OpenClaw 与已有后端，清零生产运行时的 Mock 与固定空数据。
> 审计基线：`codex/integration-p2-t10-local@9bcd854`
> 详细范围：[《第四阶段后端能力全量审计》](../../第四阶段后端能力全量审计.md)；逐项状态：[《第四阶段联调验收矩阵》](../../第四阶段联调验收矩阵.md)

## 1. 范围与完成定义

第四阶段只做真实能力接线和联调收口，不重写 OpenClaw Agent 引擎，不重做已有 React UI，不扩展新产品需求。

标准调用链：

```text
用户真实操作
-> React UI
-> preload 白名单 API
-> Electron 受控 IPC
-> U-Claw Adapter / 领域服务
-> OpenClaw Gateway、CLI、配置或 U 盘数据目录
-> 真实结果返回 UI
```

每个功能只有同时满足以下条件才能标记完成：

1. 生产 Electron 使用真实 wiring，不使用 `MockUClawClient`、fixture 或只供测试的 executor。
2. UI 读取的是真实权威数据，写操作可被 OpenClaw 或对应后端读回。
3. 成功、空数据、无服务、凭据错误、网络错误和不支持状态均可区分。
4. 至少有一条非 Mock 集成证据；外部账号或 Windows 限定项允许在本阶段标记“待真实环境验收”，但不得标记“已接通”。
5. 浏览器预览明确标识为开发模式；不用静态假数据冒充真实状态。

## 4. 联调环境配置

项目根目录使用两个文件：

- `.env.example`：可提交的完整字段模板，每个字段注明用途、是否必填和安全边界。
- `.env`：本机联调值，已由 `.gitignore` 忽略，禁止提交、截图或写入日志。

字段按下列组织，不把所有值都设为必填：

1. OpenClaw Runtime/Gateway：本地 runtime、Gateway URL/端口、可选鉴权、CLI 路径。
2. 数据与开发：U-Claw 数据目录、renderer URL、明确的 Mock 开关。
3. Provider：国产 Provider、OpenAI-compatible、Ollama/LM Studio、Proxy/`NO_PROXY`。
4. 能力：SkillHub.cn、Plugin Registry、MCP 测试服务。
5. 渠道：Telegram、QQ、飞书、企微的测试凭据；个人微信不把二维码或会话数据写入 `.env`。
6. 第三阶段：New API management/data endpoint、License endpoint、测试证书/公钥路径；签名私钥不进入客户端 `.env`。
7. 发行：Release feed URL 和公钥；发行签名私钥不进入客户端 `.env`。

实际字段名必须以已有生产代码的环境变量读取点为准。实现前先完成读取点盘点，禁止创建代码不读取的装饰性字段。

## 5. 联调记录和状态规则

`P4-T08` 维护唯一验收矩阵，每行至少记录：

```text
功能编号 | UI 操作 | 权威后端 | 调用链 | 环境 | 成功证据 | 失败证据 | 状态
```

状态只允许：

- `未接线`：UI 仍使用 Mock、固定值、空数组或 `Unsupported`。
- `已接线待联调`：生产调用链存在，尚无真实后端成功证据。
- `本地真实通过`：本机真实 OpenClaw/文件/本地服务已通过。
- `待外部环境`：只缺账号、Windows、物理 U 盘或远程服务。
- `已验收`：真实成功与失败路径都有证据。

不得使用“页面可见”、“typecheck 通过”、“Mock E2E 通过”或“localhost fixture 通过”代替真实接线状态。

## 6. 测试与阶段边界

- 开发机先完成 OpenClaw Gateway、会话、文件、记忆、工具、MCP、日志和可用本地 Provider 接线。
- 外部 Provider 和渠道在凭据填写后按功能包联调；凭据不写入测试 fixture、快照或 Git。
- Windows、Defender、无 Node.js、物理 U 盘、换机、换盘符、拔盘和正式发行判断仍属于 `P3-T08`。
- `P3-T08` 不再承担已知 Mock/未装配/空列表缺口的主体开发；这些缺口必须先在第四阶段收口。

## 7. 不在范围

- 新增原需求未定义的页面或后端能力。
- 用 U-Claw 自建数据库复制 OpenClaw 会话、消息或记忆。
- 将浏览器 Mock 预览改名后作为生产证据。
- 在客户端 `.env` 中保存 License/Release 签名私钥、企业上游 Key 或其他服务端秘密。
