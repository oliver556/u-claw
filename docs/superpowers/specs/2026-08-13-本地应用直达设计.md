# 本地应用直达设计

## 目标

严格识别“打开某应用”类低风险指令，不调用模型，直接启动本机应用；复杂指令仍交给 OpenClaw。

## 数据流

1. Electron 启动时扫描系统应用目录，生成受控缓存。
2. `chat.send` 先交给本地动作路由。
3. 只接受“打开/启动/运行 + 应用名”且无附件、无 Skill 的消息。
4. 命中后启动应用，并通过 OpenClaw 官方 `chat.inject` 写入用户指令和执行结果。
5. 未命中时自动重扫一次；仍未命中则原样回退 OpenClaw。
6. 历史映射只把带内部受控标签的注入消息恢复为用户角色。

## 安全边界

- 缓存路径每次使用前重新验证，必须位于允许扫描根目录且类型匹配。
- 不执行来自消息的命令、参数或路径。
- 不拦截“在 WPS 中写合同”等复合任务。
- 回写失败必须返回错误，不伪装完整成功。

## 验收

- 已安装应用 0 次模型调用即可打开。
- 新安装应用首次未命中时自动重扫并打开。
- 不明确、复合、带附件或 Skill 的消息继续走 OpenClaw。
- 刷新后能看到用户指令和本地动作结果。
- OpenClaw 最终成功时，中间工具错误不再导致 UI 显示整轮失败。
