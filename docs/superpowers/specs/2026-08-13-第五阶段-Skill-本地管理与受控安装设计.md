## 1. 设计结论

U-Claw 不内嵌腾讯 SkillHub 市场。能力页使用高密度工作台列表管理本地 Skill，通过系统浏览器外跳发现 Skill。

安装支持两条入口：

1. 主路径：用户将腾讯 SkillHub 生成的安装提示词粘贴到 U-Claw 对话。
2. 备用路径：用户下载 Skill ZIP，再从能力页导入。

两条入口都进入同一受控安装事务。U-Claw 不原样执行 `curl | bash`、SkillHub CLI 或用户文本中的任意 shell 命令。

## 2. 设计读法

```text
AI 桌面能力管理
冷静精密、原生工具感
register = product
SOUL = 5
SPECTACLE = 2
DENSITY = 8
hero engine = none
```

- 继承当前 U-Claw 深色壳层、`Segoe UI Variable` 字体和 Ant Design Blue 6 `#1677FF`。
- 使用一个主色；绿、黄、红只表示语义状态。
- 间距使用 `4 / 8 / 12 / 16 / 24 / 32px`，控件圆角使用 `4 / 6 / 8px`。
- 动效仅用于抽屉、菜单、进度和成功反馈，不添加装饰动画。
- 拒绝市场卡片墙、漂浮面板、大面积空白、蓝紫发光和营销页大标题。

## 3. 信息架构

### 3.1 首屏

```text
自定义标题栏
└── 一级导航
    └── Skill 工作台
        ├── 页标题与主操作
        ├── 已安装 / 可用 / 需处理 / 可更新
        ├── 搜索、状态筛选、来源筛选、刷新
        ├── Skill 管理列表
        └── U 盘与安全信息
```

页头操作：

- `发现更多`：主操作，通过 Electron 受控外链能力打开 `https://skillhub.cloud.tencent.com/skills`。
- `导入 Skill`：次操作，打开 ZIP 导入对话框。

### 3.2 列表

桌面列固定为：

| 列 | 内容 | 对齐 |
| --- | --- | --- |
| Skill | 图标、名称、标签和单行说明 | 左 |
| 来源 | 用户导入、随包内置、共享目录等 | 左 |
| 版本 | 当前版本 | 左，等宽数字 |
| OpenClaw 状态 | 可用、已禁用、缺少依赖、冲突或读取失败 | 左 |
| 启用 | 开关 | 左 |
| 操作 | 更多菜单 | 中 |

行高采用舒适档 `64–72px`。列表不展示开发者路径或完整缺失集合，但要在状态列显示用户可行动的根因。

### 3.3 行操作菜单

- 查看详情。
- 更新，仅在可更新时显示。
- 打开位置，仅开放由 Desktop 解析的已安装目录。
- 查看修复建议，仅在状态异常时显示。
- 卸载，对随包内置 Skill 不显示。

## 4. Skill 详情抽屉

详情使用右侧抽屉，不使用弹窗，避免阻断列表上下文。抽屉包含：

- 名称、slug 和版本。
- 说明与 OpenClaw 实际可用结论。
- 来源、安装位置和当前/最新版本。
- 依赖、冲突和修复建议。
- 权限与风险摘要。
- 更新可用性和回滚说明。

编辑、确认和卸载不在抽屉内嵌套新弹窗。破坏性操作关闭抽屉后再打开独立 `AlertDialog`。

## 5. AI 安装指令流程

### 5.1 触发

Composer 发送前对用户文本执行纯解析，只识别：

- 明确引用 `https://skillhub.cn/install/skillhub.md` 的安装句式。
- 明确的 `@namespace/skill` 身份。
- 后续经验证可稳定解析的腾讯 SkillHub 详情链接。

解析器只返回结构化候选，不执行任何网络、文件或子进程操作。解析不唯一、身份缺失或格式不受支持时，消息走普通聊天。

### 5.2 确认

解析成功后，发送原消息，同时展示 SkillHub 安装检测状态。Desktop 受控获取详情和包元数据后，打开安装确认对话框，展示：

- 名称、身份、版本和来源。
- 安装位置类型，不显示可编辑绝对路径。
- 权限、风险和 API Key 需求。
- 对现有版本的影响与回滚策略。

SkillHub 缺少可验证精细权限 schema 时，网络来源 Skill 统一按高风险确认，不伪造低风险精度。

### 5.3 执行与结果

```text
resolve identity
-> fetch metadata and ZIP
-> validate bundle
-> stage
-> replace
-> persist
-> OpenClaw readback
-> success or rollback
```

- 安装进度使用现有 `SkillOperation` 阶段模型。
- 安装成功后，聊天显示名称、版本和 OpenClaw 可用结论，Skill 页同步可见。
- 安装失败时，聊天显示失败阶段、简明原因和重试入口。
- 不把 shell 输出、临时路径或内部堆栈暴露给普通用户。

## 6. ZIP 导入流程

1. 用户点击“导入 Skill”。
2. 对话框通过受控文件选择器接收一个 `.zip`，最大 20 MB。
3. Desktop 把文件复制到受控临时暂存目录。
4. 校验文件数、解压大小、路径、大小写等价名、Win32 设备别名、ADS、尾随点/空格、ancestor conflict 和 canonical `SKILL.md`。
5. 校验 `name`、`description`、`slug`、`version` 与包身份。
6. 显示和 AI 安装指令相同的风险确认。
7. 经用户确认后进入现有暂存、替换、持久化、回滚和 OpenClaw 读回流程。

ZIP 路径不依赖 SkillHub 网站内部 API，也不将 ZIP 上传 U-Claw 服务器。

## 7. 系统边界

### 7.1 新增边界

建议新增三个独立单元：

1. `SkillInstallIntentParser`：纯函数解析器，只输出结构化安装候选。
2. `SkillImportService`：管理受控文件选择、暂存、校验与清理。
3. `SkillInstallCoordinator`：把聊天意图或 ZIP 导入转为现有 `SkillService` 安装事务。

三者不取代当前 bundle validator、Skill Service 和 OpenClaw runtime readback。

### 7.2 IPC 原则

- Renderer 只传递文件选择令牌、Skill 结构化身份和用户确认。
- Desktop 解析 U 盘安装根目录，不接受 renderer 传入任意绝对路径。
- 外跳只允许精确 HTTPS 白名单；首版只允许 `https://skillhub.cloud.tencent.com/skills` 及该页的查询参数。
- 新增 schema 必须使用 strict discriminated union，并为正向、未知字段和危险输入添加契约测试。

## 8. 状态与错误

| 状态 | UI |
| --- | --- |
| 初始加载 | 与列表行等高的骨架屏 |
| 未安装 | 说明原因，提供“发现更多”和“导入 Skill” |
| 无搜索结果 | 显示当前条件并提供清除筛选 |
| OpenClaw 断开 | 保留本地列表，运行状态标为未知，提供重试 |
| 安装中 | 显示阶段、进度和当前 Skill，防止重复提交 |
| 成功 | `aria-live="polite"` toast，列表保留结果 |
| 校验失败 | 说明包不可安装的具体原因，不留暂存数据 |
| 替换失败 | 自动回滚，显示旧版本仍可用 |

## 9. 测试与验收

### 9.1 单元和契约

- 安装意图解析器覆盖官方提示词、多个身份、缺失身份、伪造 URL、shell 注入和普通聊天。
- ZIP 导入覆盖大小限制、压缩炸弹、路径穿越、大小写冲突、Win32 别名、ADS、非法字符和 `SKILL.md` 身份冲突。
- IPC 覆盖未知字段、过期令牌、任意绝对路径和非白名单外链。

### 9.2 集成

- 从聊天安装指令到风险确认、安装和 OpenClaw 读回。
- 从 ZIP 选择到校验、安装和 OpenClaw 读回。
- 更新失败后旧版本回滚可用。
- 卸载后列表、安装记录和 OpenClaw runtime 同时消失。

### 9.3 UI

- `1440×900`、`960×640` 和窄屏布局无溢出或水平滚动。
- 搜索、筛选、开关、操作菜单、抽屉和对话框可键盘操作。
- 加载、空、错误、成功和禁用状态都有可见结果。
- 文本对比度符合 WCAG AA，所有图标按钮有 tooltip 和 `aria-label`。

## 10. 非目标

- 不建设 U-Claw Skill 市场。
- 不安装 SkillHub CLI，不配置全局优先源。
- 不实现付费、登录、发布、专家包或 Soul。
- 不给普通用户恢复 Curator、Proposals 和开发者运行状态入口。
- 不假设腾讯 SkillHub 已提供自定义协议或稳定公开 API。
