# U-Claw 真实模型对话与消息布局设计

> 状态：已确认
>
> 确认日期：2026-08-13

## 1. 目标

1. 新客户端可通过现有 OpenClaw 主链完成真实模型对话。
2. 用户消息显示在右侧，助手消息显示在左侧。
3. 第一版只向用户提供 `GPT-5.6 Sol`，实际模型 ID 为 `gpt-5.6-sol`。
4. 真实 Provider API Key 不进入正式客户端、EXE、U 盘、renderer、日志或诊断导出。

## 2. 消息布局

采用已确认的极简双气泡布局：

- 用户消息：右对齐，Ant Design 主蓝色气泡。
- 助手消息：左对齐，浅色气泡；暗色模式使用对应语义色。
- 双方均不显示头像和名称。
- 工具调用、审批、错误和运行状态不伪装成用户消息，继续按左侧系统流展示。
- 气泡宽度使用稳定的响应式上限，长 Markdown、代码和附件不能撑破对话区。

## 3. 模型产品规则

- 第一版模型选择器只显示 `GPT-5.6 Sol`。
- 第一版不调用 `/models` 自动暴露 Provider 返回的其他 GPT 模型。
- 默认模型和“GPT”产品别名都映射到 `gpt-5.6-sol`。
- Claude 等其他系列后续按已审核的产品目录单独加入，不因 Provider 返回而自动出现。

## 4. 当前开发联调

开发阶段临时读取根目录 `.env`：

```text
UCLAW_TEST_PROVIDER_BASE_URL
UCLAW_TEST_PROVIDER_API_KEY
UCLAW_TEST_PROVIDER_MODEL=gpt-5.6-sol
```

这些变量只用于本地开发联调，不是发行凭据格式。`.env` 不提交 Git，不进入安装包或 EXE。

Electron 主进程负责读取和校验配置，并幂等同步到 OpenClaw Provider 配置。renderer 不读取 Base URL 或 API Key。聊天必须沿用现有主链：

```text
React UI
-> 受控 Electron IPC
-> Adapter
-> OpenClaw Gateway
-> OpenAI-compatible Provider
```

禁止 renderer 直接请求 `/chat/completions`，也禁止为了临时跑通而绕过 OpenClaw。会话、工具、Skill、记忆和文件能力继续由 OpenClaw 承载。

## 5. 正式发行架构

```text
客户端激活码 + USB 设备身份
-> 激活后台验证许可证和设备状态
-> 签发短期、受限客户端 Token
-> 客户端通过 Token 访问 U-Claw AI 网关
-> AI 网关使用服务端 Provider API Key
-> 上游模型
```

边界：

- Provider API Key 只保存在 AI 网关服务端。
- 激活后台负责许可证、设备状态和短期 Token 签发，不向客户端返回 Provider API Key。
- 客户端 Token 绑定许可证、设备、允许模型、额度和有效期，并支持撤销和轮换。
- 短期 Token 由 Electron 主进程或 OpenClaw 受控配置使用，不进入 renderer。
- URL 和产品模型目录可以随发行包提供并接受签名校验，但它们不是秘密。
- 从开发 `.env` 切换到正式短期 Token 时，只替换凭据来源和服务端目标，不改 React、IPC、Adapter 或 OpenClaw 对话协议。

## 6. 错误处理

- 开发配置缺失：返回可诊断的“模型服务未配置”，不回退 mock。
- Provider 认证、余额、限流、模型不存在和网络错误：保留分类错误，不静默切换来源。
- 正式 Token 过期：主进程向激活后台刷新；刷新失败时停止在线推理并给出恢复动作。
- 所有错误、日志和 IPC 响应必须脱敏，不包含 API Key、完整 Token、Authorization 头或对话正文。

## 7. 验证范围

实现阶段至少验证：

1. 用户消息右侧、助手消息左侧，双方无头像和名称。
2. 第一版只展示并默认选择 `GPT-5.6 Sol`。
3. `.env` 配置由主进程读取并同步，renderer 无法取得完整 API Key。
4. 真实消息经过 OpenClaw Gateway，并返回 `gpt-5.6-sol` 回复。
5. 刷新或切换会话后，真实消息仍由 OpenClaw 权威会话读回。
6. 认证失败、模型错误和网络错误不会回退 mock 或其他 Provider。
7. 秘密扫描不发现 `.env`、API Key、完整 Token 或 Authorization 头。

正式发行前另需验证激活后台、AI 网关、短期 Token、撤销、额度、限速和真实 Windows/U 盘环境；本次本地联调不冒充这些生产验收。
