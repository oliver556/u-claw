# 对话图片预览与系统操作设计

日期：2026-08-14

## 目标

补齐对话图片从“可显示”到“可操作”的完整桌面链路：

- 单击图片打开大图预览。
- 预览支持适应窗口、缩放、原始像素和拖拽平移。
- 图片右键支持“复制图片”和“另存为图片”。
- 系统剪贴板、保存对话框和文件写入统一由 Electron 主进程执行。
- 所有图片读取继续受 Gateway 鉴权和受控 URL 约束。

本期不做图片编辑、裁剪、标注、图库浏览、批量下载和图片格式转换。

## 现状

`MessageContent` 直接把 `ContentBlock` 的 `sourceUrl` 渲染为 `<img>`。当前图片可以显示，但没有预览层、缩放状态、右键菜单，也没有图片复制或保存 IPC。

`sourceUrl` 只允许两类来源：

- Gateway managed outgoing media：`/api/chat/media/outgoing/...`
- Gateway assistant media：`/__openclaw__/assistant-media?source=...`

Electron 已为这些受控请求注入 Gateway Bearer token。新链路必须复用同一安全边界，不能让 Renderer 直接访问任意网络 URL或本地文件路径。

## 交互设计

### 对话缩略图

- 保持现有对话内图片尺寸和布局。
- 图片具有可点击语义和放大光标。
- 单击打开全屏遮罩预览。
- 右键打开应用菜单，包含“复制图片”和“另存为图片”。
- 图片加载失败时保留现有消息布局，显示稳定失败占位，不暴露本地路径。

### 全屏预览

采用已确认的 Codex 式全屏遮罩方案：

- 深色全屏遮罩承载图片，不使用装饰卡片。
- 右上角紧凑工具栏：缩小、`100%`、放大、复制、关闭。
- 默认状态为“适应窗口”，保持宽高比，不拉伸、不裁剪。
- 缩放范围 `25%–400%`，按钮步进 `25%`。
- `100%` 表示一个图片像素对应一个屏幕 CSS 像素。
- 滚轮执行缩放；放大后可拖拽平移。
- 每次打开新图片重置为适应窗口。
- `Esc`、关闭按钮或点击图片外遮罩关闭预览。
- 点击图片和工具栏本身不关闭预览。
- 焦点进入预览层；关闭后回到原缩略图。
- 页面滚动在预览期间锁定，关闭后恢复。

### 右键菜单

- 缩略图和预览图均支持相同菜单。
- 菜单项：`复制图片`、`另存为图片`。
- 菜单由 Renderer 展示和定位，系统操作通过受控 IPC 请求主进程。
- 操作执行中禁用重复触发。
- 成功或失败用短时轻提示反馈。
- 取消“另存为”不显示错误，也不产生文件。

## 架构

### Frontend

新增独立图片交互组件，职责拆分如下：

- `MessageImage`：渲染缩略图，处理打开预览和右键入口。
- `ImagePreview`：管理遮罩、缩放、平移、焦点和键盘交互。
- `ImageContextMenu`：展示复制和另存菜单，不直接访问系统能力。
- 图片操作 bridge：向 preload 发送经过 shared schema 校验的请求，统一处理进行中与结果状态。

`MessageContent` 只负责按 block 类型选择 `MessageImage`，不承载预览状态机。

### Shared Contract

新增窄范围图片操作 IPC 契约：

- 方法：`image.copy`、`image.save`。
- 输入：`requestId`、受控 `sourceUrl`、建议文件名。
- 输出：成功、用户取消，或经过脱敏的稳定错误。
- `sourceUrl` 使用与 `ContentBlockSchema` 相同的受控 URL 校验规则，避免前后端规则漂移。
- 建议文件名只保留安全基础文件名，不能携带目录。

### Preload

preload 只暴露最小 `window.uclaw.images.invoke()` 能力：

- 请求和响应均经 shared schema 校验。
- 校验 `requestId` 和 `method` 相关性。
- 不向 Renderer 暴露 Electron `clipboard`、`dialog`、`nativeImage`、文件系统或 Gateway token。

### Electron Main

主进程图片服务负责：

1. 校验 IPC sender 为当前受信任 WebContents。
2. 再次解析并校验受控 `sourceUrl`。
3. 将相对 managed media URL 绑定到当前 loopback Gateway origin。
4. 仅允许当前 Gateway 端口和两个已批准路径。
5. 使用当前 Gateway token 读取图片；managed outgoing 请求同时注入 session key header。
6. 拒绝重定向、非 `2xx`、非图片 MIME、空响应和超限响应。
7. 读取完成后再执行复制或保存。

建议最大图片响应为 `32 MiB`。读取采用流式累计并在超限时立即中止，不能先无限读入内存。

## 复制图片

- 主进程使用 `nativeImage.createFromBuffer()` 解码图片。
- 解码结果为空时返回稳定错误。
- 使用 `clipboard.writeImage()` 写入系统剪贴板。
- 不把原始路径、Gateway token、响应头或底层异常回传 Renderer。
- PNG、JPEG、WebP 等由 Electron 解码支持决定；不支持的真实图片 MIME 返回“无法复制此图片格式”。

## 另存为图片

- 根据已验证 MIME 决定默认扩展名，不能只信任建议文件名。
- 调用原生 `showSaveDialog()`。
- 取消时返回 `cancelled`。
- 目标必须为用户在保存对话框中明确选择的单个文件。
- 在目标目录创建独占临时文件，完整写入、同步后原子改名。
- 写入或改名失败时清理本次临时文件，不覆盖不相关文件。
- 默认允许用户确认覆盖；具体覆盖行为遵循 Electron 保存对话框结果和现有安全文件工具约束。

## 错误处理

Renderer 只显示稳定中文提示：

- `图片读取失败，请重试。`
- `无法复制此图片。`
- `图片保存失败，请重试。`

主进程诊断日志可记录操作类型、错误分类、MIME、字节数和 correlation ID，但不得记录 token、完整本地源路径或图片内容。

预览、复制和保存互不绑定：预览加载失败不应使会话页面崩溃；复制失败不应关闭预览；保存取消不算失败。

## 安全边界

- Renderer 不能提交任意 `http(s):`、`file:`、`data:` 或本地绝对路径。
- URL 必须命中现有两类受控图片地址，并通过严格 percent 编码校验。
- 主进程拒绝跨主机、跨端口和重定向。
- 主进程不接受 Renderer 提供的 Authorization header、session key 或目标目录。
- 响应必须具有受支持图片 MIME，且大小不超过 `32 MiB`。
- IPC handler 必须执行 sender 授权和请求相关性校验。

## 测试

### Frontend

- 点击缩略图打开预览。
- `Esc`、遮罩和关闭按钮关闭，并恢复焦点。
- 默认适应窗口；缩放上下限与步进正确。
- `100%`、滚轮缩放和拖拽平移正确。
- 右键菜单展示两个操作。
- 进行中防重复触发；成功、失败、取消反馈正确。

### Shared / Preload / IPC

- 两类合法 `sourceUrl` 通过。
- 任意网络 URL、本地路径、畸形 percent 编码和额外查询参数被拒绝。
- IPC method、requestId 和响应相关性强校验。
- 未授权 sender 被拒绝。

### Main Process

- Gateway token 与 managed outgoing session header 正确注入。
- 重定向、非图片 MIME、超限响应、空响应和解码失败被拒绝。
- `clipboard.writeImage()` 获得有效 `NativeImage`。
- 保存取消不写文件。
- 保存成功采用临时文件和原子改名。
- 写入失败清理临时文件，且不泄露底层路径。

### 真实验收

- macOS 开发环境验证点击预览、缩放、复制到系统剪贴板、粘贴到支持图片的应用、另存后重新打开。
- Windows 便携版验证同一流程，确认数据仍位于 U 盘，保存目标仅由用户选择。
- 验证历史 `MEDIA:` 转换图片与 managed outgoing 图片行为一致。

## 完成标准

- 对话图片可单击进入已确认的 B 型全屏预览。
- 缩放、平移、关闭、焦点和滚动行为稳定。
- 缩略图和预览图均可右键复制或另存。
- Renderer 不获得系统剪贴板、文件系统或 Gateway 凭据权限。
- 安全、IPC、组件和主进程测试通过。
- macOS 开发环境真实复制与保存验收通过；Windows 便携版保留明确验收项。
