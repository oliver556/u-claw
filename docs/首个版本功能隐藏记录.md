# U-Claw 首个版本功能隐藏记录

## 1. 文档信息

- 适用版本：首个对外发布版本（V1）
- 记录日期：2026-08-13
- 目的：缩小首版产品范围，降低上线风险，优先保留核心使用链路。
- 性质：临时隐藏，不代表功能永久删除。

## 2. 处理原则

1. 首版仅隐藏对应 UI 入口、导航项、选项和状态文案。
2. 已实现代码、后端能力、数据结构和配置默认保留，除非实现隐藏必须调整。
3. 隐藏项不应占据布局空间，不展示空白占位、分隔符或无效提示。
4. 用户不应通过菜单、快捷键、默认跳转或其他可见入口进入已隐藏功能。
5. 后续恢复时，应能通过小范围代码或配置调整重新开放。

## 3. 隐藏清单

### 3.1 主侧边栏

隐藏：

- `文件`
- `记忆`
- 侧边栏底部 `自动化`

保留：

- `工作`
- `能力`
- `连接`
- `系统`

### 3.2 渠道连接

首版仅保留 `个人微信`。

隐藏以下渠道的所有用户可见入口，包括渠道筛选项、新建连接选项、渠道卡片和相关操作入口：

- `Telegram`
- `QQ Bot`
- `飞书`
- `企业微信`
- `Discord`

备注：如果 `全部渠道` 筛选项在仅有一个渠道时没有实际作用，首版同步隐藏渠道筛选控件，直接展示 `个人微信`。

### 3.3 系统页面

顶部一级功能仅保留：

- `发布更新`
- `外观`

隐藏：

- `诊断`
- `设备与运行`
- `语音与通知`
- `产品授权`
- `备份与存储`

默认进入 `系统` 时，应打开保留页面，不应跳转到已隐藏的 `诊断` 页面。

### 3.4 顶部全局栏

隐藏：

- 顶部全局搜索框，包括 `搜索会话、文件或能力` 文案和 `Ctrl K` 快捷键提示。
- 顶部 `模型加载中` 状态项。

同步要求：

- 全局搜索隐藏后，`Ctrl K` 不应打开搜索面板。
- 隐藏后顶栏其他状态和窗口控件自然补位，不留空白占位。

## 4. 首版保留范围

本次调整不要求隐藏以下功能：

- 工作区与会话主流程。
- 能力管理入口。
- 个人微信连接与其操作流程。
- 系统页面中的 `发布更新` 和 `外观`。
- 顶部 U 盘、Gateway 等其他运行状态。
- 窗口最小化、最大化和关闭控件。

## 5. 验收标准

1. 启动应用后，主侧边栏不展示 `文件`、`记忆`、`自动化`。
2. 进入 `连接` 后，用户只能看到并操作 `个人微信`，不能选择或新建其他渠道。
3. 进入 `系统` 后，顶部只显示 `发布更新` 和 `外观`，且默认页面可正常使用。
4. 任何主页面顶部均不展示全局搜索框和 `模型加载中`。
5. 按下 `Ctrl K` 不打开全局搜索。
6. 隐藏后无明显空白、错位、残留分隔符或不可用的交互热区。
7. 现有会话、个人微信、发布更新和外观功能不受影响。

## 6. 后续恢复记录

恢复任一隐藏功能前，需单独确认：

- 功能完整度和稳定性。
- 产品交互和视觉验收结果。
- 依赖服务、配置和安装流程是否可用。
- 是否纳入对应版本发布范围。

恢复后，在本文档追加恢复版本、日期和责任人。
