商业模型：全局启用模型向全部有效付费客户开放
计费：充值多少、使用多少
BYOK：保留，但聊天仍经过 OpenClaw
聊天权威：OpenClaw

- [ ] 第一轮图片立即展示。

### 14.4 最终放行

只有环境矩阵、业务矩阵、最终制品 smoke、CDN 回读和秘密扫描全部通过，才允许切换 `requiredReleaseSequence`。

## 15. 并行开发边界

### 15.1 可以并行

| 工作流 | 可并行对象 | 原因 |
|---|---|---|
| Shell/Gateway 生命周期 | 服务端模型目录与中转 | 主要代码目录不同 |
| 服务端 SSE/Tool | 前端 canonical mapper | 协议可先冻结 |
| 服务端图片 edits | Gateway 生命周期 | 数据面与进程面分离 |
| R2 runtime | 服务端版本策略 | manifest 合同冻结后可分工 |
| Bootstrap 客户端 | CDN/发布服务 | 共用已冻结版本协议 |
| CI 流水线准备 | 功能测试补齐 | 最终整合晚于功能完成 |

### 15.2 必须串行或单一所有者

| 冲突面 | 规则 |
|---|---|
| Electron Main Gateway 生命周期 | 工作流 A 先完成；Provider restart 后接入 |
| `product/shared` 激活/凭据 schema | 只能有一个权威修改者 |
| OpenClaw Provider 配置 | Gateway 重启合同完成后修改 |
| 旧商业直连删除 | 真机新链通过后执行 |
| runtime manifest | Bootstrap、服务端、流水线共用同一冻结版本 |
| 正式发布 | 只允许唯一流水线 |

## 16. 历史问题与验收对应

| 历史问题 | 根修复 | 必须通过的门禁 |
|---|---|---|
| 文本整段蹦出 | 商业聊天统一走 OpenClaw + 真 SSE | 多帧 SSE 真机测试 |
| 切会话丢进度 | Gateway run 独立于页面 | 切换不 `abort`，后台完成可恢复 |
| 对话无上下文 | 同一 OpenClaw session | 第二轮使用第一轮上下文 |
| 图片首次不展示 | live/history 共用 mapper | 第一轮图片立即展示 |
| 无法修改上一张 | OpenClaw transcript + `/images/edits` | 第二轮编辑上一张真机通过 |
| 新模型必须打包 | 服务端动态目录 | 增加模型不修改客户端、不打包 |
| 打一次包报一次错 | 固定工具链和唯一流水线 | 最终制品 smoke + 物理 U 盘门禁 |
| 测试包与发布包不同 | 制品一次生成、逐级晋升 | 候选/验收/正式 SHA-256 一致 |

## 17. 完成定义

四项重构只有同时满足以下条件，才算开发完成：

- [ ] 四份原始需求中的验收门禁全部通过。
- [ ] 所有商业聊天经过 OpenClaw，无模型推理直连。
- [ ] 商业模型、BYOK、文本、工具、图片生成和图片编辑真机通过。
- [ ] R2 runtime 首次安装和 warm startup 通过。
- [ ] 每次启动强制版本门禁和 License 顺序通过。
- [ ] 服务端向前回滚通过。
- [ ] `product/` 是唯一商业构建输入。
- [ ] `u-claw-app/`、根 `portable/`、旧 `release.yml` 不参与正式发布。
- [ ] 最终商业制品通过 Windows 10/11、macOS arm64 和同盘跨系统物理 U 盘矩阵。
- [ ] CDN 回读后才切换全局正式版本。
- [ ] 主播或客户不再承担首次发现构建、启动和聊天回归的职责。
