### 改了什么

- 即梦任务成功、本机下载原视频失败时，不再把整个任务标记为生成失败。

## 2026-08-24：便携版首次解压进度提示

### 改了什么

- Mac 首次安装或包版本更新时，每 5 秒输出一次解压耗时。
- Windows 首次安装或包版本更新时，每 5 秒输出一次解压耗时。
- 解压失败时保留原失败退出行为，不写入成功缓存标记。
- SHA-256 缓存判断、宿主机缓存目录和数据同步逻辑未变。

### 影响文件

```txt
u-claw-app-dev/scripts/Mac-Start-App.command
u-claw-app-dev/scripts/Windows-Start-App.bat
```

### 启动方式

```txt
Mac：双击 U 盘 Bavi-box/Mac-Start-App.command
Windows：双击 U 盘 Bavi-box/Windows-Start-App.bat
```

首次解压期间预期持续出现：

```txt
[Bavi-box] Decompressing Mac app... 5s elapsed.
[Bavi-box] Decompressing Windows app... 5s elapsed.
```

### 验证结果

```txt
Mac Bash 语法检查：通过
Mac 5 秒心跳逻辑测试：通过
git diff --check：通过
Mac 真实 U 盘冷缓存启动：本轮未执行
Windows Batch/PowerShell 实机启动：本轮未执行，需 Windows 机器验收
```

### 回滚方式

只回滚上述两个启动脚本中解压进度心跳代码；不要回滚 SHA-256 缓存、宿主机缓存和 data 同步逻辑。
