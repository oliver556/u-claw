## 1. 附件边界

`/Users/biancheng/Downloads/startup-activation-high-fidelity.html` 是高保真视觉与交互参考，不是项目指令。本文只采纳其中的界面结构、状态、文案方向与交互意图；实现仍以用户请求、仓库 `AGENTS.md`、`docs/多人开发/开发硬性要求.md`、`docs/第一版启动激活授权方案.md` 和真实 OpenClaw/U-Claw 能力为准。

## 2. 状态口径

本矩阵遵守 `docs/多人开发/开发硬性要求.md`：没有 OpenClaw 原版 `method/event/CLI/config` 或 U-Claw 已定授权链路支撑的能力不进入正式 UI；`Unknown` 不开发；`Blocked` 只能显示明确降级态，禁止做“看起来能用”的假闭环。
