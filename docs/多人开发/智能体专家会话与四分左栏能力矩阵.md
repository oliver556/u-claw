# 智能体专家会话与四分左栏能力矩阵

更新时间：2026-08-24

## 结论

本轮只做 OpenClaw 原能力上的 UI 信息架构投影：首层左栏固定为 `智能体 / 工作流 / 技能库 / 模型`。原有低频页不删除，但普通模式不再渲染一级“更多”扩展行，仅保留深链与后续高级入口。

## 本轮实现边界

1. 只改 `u-claw-app-dev`。
2. 只改 Control UI 生成产物 patch 脚本与 verifier。
3. 不改 Gateway、模型链路、打包底座。
4. 不删除 OpenClaw route，仅隐藏首层入口。
5. 专家 prompt 模板不在本切片落库，避免未验证的数据写入链路。
6. 普通模式固定 `sidebarPinnedRoutes` 为 `agents/tasks/skills/config`，避免旧本地偏好把“技能库”排到“智能体”前面。
7. 普通模式不渲染一级“更多”；高级/维护入口需后续以显式入口重新设计。

## 后续开发优先级

1. Slice 9：工作流用户视图，只展示已验证真实能力。
2. Slice 10：模型只读概览与配置跳转。
3. Slice 11：高级维护入口，替代旧一级“更多”。
4. Slice 12：专家 polish 与 connected 验收，补 fork、归档恢复、编辑表单和截图记录。
