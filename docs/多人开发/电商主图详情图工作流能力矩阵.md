# 电商主图/详情图工作流能力矩阵

更新时间：2026-09-01

## 1. 状态口径

本矩阵遵守 `docs/多人开发/开发硬性要求.md`：

- `OK`：已有 OpenClaw 原能力或权威调用方式，且已可验证，可进入正式 UI。
- `Planned`：方向明确，但需要一个实现切片和验证后才能标 `OK`。
- `Blocked`：存在明确卡点，不进入正式可用入口；只允许显示不可用、待配置或文档说明。
- `Unknown`：未确认权威调用方式，不开发。
- `Do Not Build`：不作为本阶段方向。

## 2. 结论

“电商主图/详情图”可放入左侧“工作流”，且首版应是 Workbench-first 直出体验：用户选择平台和生成类型，上传商品图，填写少量信息，直接在当前页生成主图、详情图或模特图并保留记录。它不创建 OpenClaw 聊天会话，也不复用“龙虾”路径。

## 5. 首版开发范围

V0 只包含：

1. 工作流页新增“电商主图/详情图”直出工作台。
2. 平台 preset、最小输入、图片上传、生成类型和数量选择。
3. 主图、详情图、模特图三类 direct image target。
4. 桌面端主进程直接调用图片接口，前端不接触 API key，不创建聊天会话。
5. 本页显示生成结果并保留本地生成记录。
6. 静态 verifier、UI fixture 验收、Gateway 本地烟测。

V0 不包含：

1. Prompt 文件包导出。
2. SKU 素材库。
3. 批量队列。
4. 可视化 workflow builder。
5. 平台上传/自动投放。

## 6. 验证建议

实现前验证：

```bash
cd u-claw-app-dev
node --check scripts/patch-openclaw.js
npm run patch-openclaw
node scripts/verify-skillhub-branding.js
node scripts/verify-skillhub-chat-dropdown.js
```

Skill 包验证：

```bash
OPENCLAW_HOME="/Users/biancheng/Library/Application Support/u-claw" \
OPENCLAW_STATE_DIR="/Users/biancheng/Library/Application Support/u-claw/.openclaw" \
OPENCLAW_CONFIG_PATH="/Users/biancheng/Library/Application Support/u-claw/.openclaw/openclaw.json" \
node u-claw-app-dev/node_modules/openclaw/openclaw.mjs skills list --json
```

V0 验收：

- 用户能选择主图、详情图、模特图，并且选择会进入 direct image payload。
- 用户上传 1 张商品图并填写商品名或卖点后，能在当前页点击生成图片。
- 生成结果在当前页展示，记录包含平台、商品、生成类型、素材数量、图片数量、模型和状态。
- 左侧“工作流”不出现不可用 builder、批量队列或平台上传真按钮。
- Gateway 返回 HTTP 200，文本对话 P0 baseline 不受影响。
