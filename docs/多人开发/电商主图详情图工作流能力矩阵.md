# 电商主图/详情图工作流能力矩阵

更新时间：2026-08-31

## 1. 状态口径

本矩阵遵守 `docs/多人开发/开发硬性要求.md`：

- `OK`：已有 OpenClaw 原能力或权威调用方式，且已可验证，可进入正式 UI。
- `Planned`：方向明确，但需要一个实现切片和验证后才能标 `OK`。
- `Blocked`：存在明确卡点，不进入正式可用入口；只允许显示不可用、待配置或文档说明。
- `Unknown`：未确认权威调用方式，不开发。
- `Do Not Build`：不作为本阶段方向。

## 2. 结论

“电商主图/详情图”可放入左侧“工作流”，但首版只做 OpenClaw Skill/Agent/session 驱动的 Prompt-only 工作流。直接出图、素材库、批量队列和可视化编排器需要后续验证，不得在 V0 伪装可用。

## 5. 首版开发范围

V0 只包含：

1. 工作流页新增“电商主图/详情图”卡片。
2. Skill 包审计和 OpenClaw 可读安装/绑定。
3. 专用 Agent/session 启动。
4. Prompt-only 分阶段流程：intake、合规边界、Campaign Style Lock、策略确认、Storyboard 确认、Prompt Pack、QA。
5. 静态 verifier、Prompt-only fixture 验收、Gateway 本地烟测。

V0 不包含：

1. 直接出图。
2. Prompt 文件包导出。
3. SKU 素材库。
4. 批量队列。
5. 可视化 workflow builder。
6. 平台上传/自动投放。
