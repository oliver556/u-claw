# U-Claw 客户端界面设计规范

> 状态：亮色主题已确认，可作为开发基线
>
> 确认日期：2026-08-07
>
> 原型：`outputs/uclaw-ui-prototype/`
>
> 关联文档：《客户端色彩规范》、《客户端改造需求》、《Adapter 契约草案》

## 1. 设计定位

U-Claw 是长时间常驻的 AI 桌面工作客户端，不是营销网页，也不是 OpenClaw Dashboard 的浏览器套壳。

设计参数：

- 界面类型：Product UI。
- 视觉气质：冷静、可靠、紧凑、桌面原生感。
- `SOUL=5`：有 U-Claw 辨识度，不影响工作效率。
- `SPECTACLE=2`：动效只用于状态和操作反馈。
- `DENSITY=7`：同屏保留会话、工作区和上下文。
- 主色：Ant Design Blue 6 `#1677FF`。
- 当前实现：亮色主题。
- 暗色主题：色彩 token 已设计，全部产品功能完成后逐页实现。

禁止默认风格：紫蓝发光 AI 页、大面积渐变、漂浮卡片墙、浏览器标签页感、为装饰而动画。

## 2. 信息架构

### 2.1 一级导航

| 入口 | 用户任务 | 第一阶段 | 第二阶段 |
| --- | --- | --- | --- |
| 工作 | 会话、工具执行、任务产物 | 完整主链 | 活动中心、产物页签 |
| 文件 | 查看工作区和会话文件 | 读取、打开 | 搜索、重命名、移动、删除 |
| 记忆 | 查看 Agent 记忆 | 只读入口 | 搜索、编辑、删除、冲突处理 |
| 能力 | 管理模型、技能、插件和 MCP | 当前模型和工具只读 | 完整管理 |
| 连接 | 管理 Telegram、QQ、飞书、微信等渠道 | 稳定入口和状态占位 | 配置、登录、测试和断开 |
| 系统 | 运行状态、日志、诊断、更新 | 状态、数据目录、高级控制台 | 完整维护能力 |

一级入口在两个阶段不变。第二阶段只填充能力，不重构整体导航。

### 2.2 工作页结构

```text
自定义标题栏
└── 一级导航栏
    ├── 会话栏
    ├── 工作画布
    └── 上下文舱
```

- 标题栏：品牌、全局搜索、U 盘状态、Gateway 状态、当前模型、Windows 窗口按钮。
- 会话栏：新建会话、搜索、分组、会话列表和用量摘要。
- 工作画布：会话头、消息流、工具轨迹、结果块和输入区。
- 上下文舱：文件、记忆、活动三个页签。

## 3. 窗口与布局

### 3.1 桌面窗口

| 区域 | 基准值 | 约束 |
| --- | ---: | --- |
| 标题栏 | `48px` | 整行可拖动，交互控件使用 `no-drag` |
| 一级导航 | `72px` | 图标加文字，当前项显式高亮 |
| 会话栏 | `264px` | 可收起为 `0` |
| 上下文舱 | `300px` | 可收起为 `0` |
| 工作画布 | `minmax(470px, 1fr)` | 永远优先保留 |
| 消息内容 | 最大 `760px` | 居中，长文保持可读性 |

建议最小窗口：`960×640`。低于建议尺寸时进入窄屏策略，不依靠水平滚动。

### 3.2 响应式规则

| 视口 | 行为 |
| --- | --- |
| `>1180px` | 四栏同时展示 |
| `901–1180px` | 缩小会话栏和上下文舱 |
| `681–900px` | 上下文舱变为右侧覆盖层 |
| `≤680px` | 一级导航改为底部导航；会话栏和上下文舱改为抽屉 |

窄屏底部导航最多直接展示 5 项。“连接”和“系统”收入“更多”菜单。

### 3.3 Windows 桌面行为

- 使用无系统 frame 窗口和自定义标题栏。
- 最小化、最大化/还原、关闭按钮的位置、热区和反馈对齐 Windows 习惯。
- 双击标题栏切换最大化。
- 最大化状态通过 preload IPC 同步给 React，更新还原图标。
- 渲染进程不得获得任意窗口、文件系统或子进程权限。

## 4. 视觉系统

### 4.1 色彩

所有颜色从《客户端色彩规范》的语义 token 取值。业务组件禁止散写 Hex、RGB 或 HSL。

产品状态固定映射：

- 蓝色：主操作、当前选中、连接中、流式生成中。
- 绿色：已就绪、已落盘、执行成功。
- 黄色：待授权、已降级、空间偏低。
- 红色：断开、写入失败、危险操作。
- 中性灰：未配置、空闲、辅助信息。

### 4.2 字体与文字

- UI 字体：`"Segoe UI Variable", "Segoe UI", system-ui, sans-serif`。
- 代码和路径：`ui-monospace, "Cascadia Mono", Consolas, monospace`。
- 业务界面字间距固定为 `0`。
- 主画布正文基准 `14px/1.65`；元数据 `12px/1.4`。
- 紧凑面板标题 `16–17px`，不使用营销页大标题。
- 数值和计时使用 `font-variant-numeric: tabular-nums`。

### 4.3 间距与圆角

- 基本间距单位：`4px`。
- 常用间距：`4 / 8 / 12 / 16 / 24 / 32px`。
- 小控件圆角：`4px`。
- 按钮、列表项、图标容器：`6px`。
- 输入器、工具块、弹窗：`8px`。
- 禁止大面积胶囊化和多套圆角系统。

### 4.4 图标

- React 实现使用 `lucide-react`。
- 工具按钮优先使用熟悉图标，并提供 tooltip 和 `aria-label`。
- 标准图标不手画 SVG。品牌标识可使用独立资产。
- 图标基准 `16px`，一级导航 `20px`。

## 5. 组件规范

### 5.1 会话列表

- 每行基准高度 `62px`，包含标题、摘要、时间或状态。
- 当前会话使用选中背景，不仅依赖文字颜色。
- 标题和摘要单行截断，tooltip 显示完整值。
- 重命名、固定、删除收入行操作菜单，删除使用确认对话框。

### 5.2 消息

- Agent 消息默认无大面积卡片外框，保持长文可读性。
- 用户消息使用弱底色和边界，不使用高饱和气泡。
- Markdown 覆盖标题、列表、表格、引用、链接、行内代码和代码块。
- 外部链接经 Electron 白名单 IPC 打开，不在客户端窗口中替换页面。

### 5.3 工具轨迹和审批

- 工具块固定支持：等待、运行、成功、失败、已取消。
- 摘要行展示工具名、当前状态、耗时，详情默认折叠。
- 参数、路径和输出经脱敏后展示。
- Exec 审批和 Plugin 审批是两种业务类型，UI 文案和决策选项不得混用。
- 高风险操作必须同时展示对象、范围和后果。

### 5.4 输入区

- 文本区自动增高，高度范围 `52–150px`。
- 左侧放附件、工具模式等低频控件；右侧固定发送/停止。
- 生成中发送按钮替换为停止按钮，保持尺寸不变。
- 附件状态放在输入器上方，不覆盖文本。
- 断线时保留草稿；只禁用不能完成的操作，并给出原因。

### 5.5 上下文舱

- 页签数量固定为 3：文件、记忆、活动。
- 页签可显示数量徽标，不使用红色表示普通计数。
- 选中消息、工具或产物时，内容联动到对应页签。
- 面板收起后，在工作画布头部保留恢复入口。

## 6. 交互与状态

每个远程数据视图必须实现：

1. 初始加载：与最终布局同尺寸的骨架屏。
2. 空状态：原因、下一步操作和明确 CTA。
3. 局部错误：原位展示，保留用户输入。
4. 全局断线：常驻状态带加重连操作。
5. 成功：3–5 秒 `aria-live="polite"` toast，重要结果保留在页面。
6. 降级：显示缺失的 Capability，不伪装完整可用。

状态变化动效仅允许 `transform` 和 `opacity`，基准时长 `120–180ms`，缓动 `cubic-bezier(.16,1,.3,1)`。`prefers-reduced-motion: reduce` 时关闭非必要动效。

## 7. 可用性和无障碍

- 所有功能可用键盘到达，焦点环不得只靠浏览器默认样式。
- 正文对比度至少 `4.5:1`，大字和 UI 图形至少 `3:1`。
- 窄屏触摸热区至少 `44×44px`。
- 不仅使用颜色表示错误、成功或选中状态。
- 图标按钮提供 `aria-label`；不熟悉图标提供 tooltip。
- 弹窗打开时锁定焦点，关闭时返回触发元素。
- Windows `100% / 125% / 150%` 缩放均需通过主流程验收。

## 8. 技术落地规则

- React 使用 Ant Design 组件和 ConfigProvider 主题算法。
- 页面不直接调用 OpenClaw RPC，只依赖 `product/shared` 契约和 Adapter client。
- 布局尺寸、语义色、字号、圆角和层级都使用 token。
- 外壳布局、会话列表、工作画布和上下文舱分开实现，不集中到单个大组件。
- 服务端状态使用查询缓存；窗口和面板偏好使用本地 UI state。
- 原型仅是交互和视觉证据，不直接复制其原生 JavaScript 为正式架构。

## 9. 第一阶段界面验收

- [ ] 桌面窗口无浏览器地址栏和网页外壳感。
- [ ] 工作、文件、记忆、能力、连接、系统入口位置稳定。
- [ ] 会话列表、消息历史、发送、停止、流式输出可用。
- [ ] 工具轨迹、审批、错误和重连状态准确。
- [ ] 两侧面板可收起，窄窗不遮挡主工作区。
- [ ] `960×640`、`1440×900` 和 `1920×1080` 无布局溢出。
- [ ] Windows `100% / 125% / 150%` 缩放主流程通过。
- [ ] 业务 CSS 无主题外散写色值。
- [ ] 键盘导航、焦点、对比度和减少动效通过验收。
- [ ] 暗色主题不在全部业务功能完成前开工。
