## 集成结论

- Go signer、OpenAPI、shared schema、Desktop verifier 使用同一 startup license canonical。
- `failed_before_bind` 与 `server_bound` 端到端保留；事务提交结果不明进入恢复流程。
- Desktop 首激活与 Launcher 启动 gate 复用同一 startup license 公钥集合。
- release feed 固定 `https://updates.u-claw.org/releases/`，release trust 与 activation trust 分离。
- activation-only 仅开放五个受限 IPC；退出码 20 后 Launcher 最多重跑一次完整 gate。
