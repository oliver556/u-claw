## 关键发现

- 当前 VPS 上运行的是旧版 `product/activation-server` 风格的 activation/model proxy 服务；它已有双实例、Caddy allowlist、device-token 模型代理和 `new_api_bindings`。
- 当前本地新开发的 `u-claw-app-dev/cloud/uclaw-cloud-api` 手机号登录、New API 自动开户、充值订单体系尚未部署到该 VPS。
- 当前 `PUBLIC_MODEL_ENDPOINT` 是 `https://121.41.89.103/model-api/`，不是 `https://license.yiyong.me/model-api/`。
- `license.yiyong.me` DNS 指向 `121.41.89.103`，但本机访问 `https://license.yiyong.me/health/ready` TLS 握手失败；域名证书/ACME 仍需单独处理。
