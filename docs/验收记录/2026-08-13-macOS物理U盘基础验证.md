# macOS 物理 U 盘基础验证

日期：2026-08-13
结果：`pass`（仅 macOS 介质基础能力及人工重插）
发布门禁：`blocked` / `not-release-ready`

## 范围

用户确认该 U 盘为新购专用测试盘，并明确授权清空。测试在 macOS 26.4.1 arm64 执行；不覆盖 Windows、Defender、普通用户、Launcher、激活服务、正式签名发行物或跨机行为。

## 介质

- 整盘设备：`/dev/disk4`
- 分区：`/dev/disk4s1`
- 类型：外置、可移除、USB
- 容量：15.7 GB
- 文件系统：ExFAT
- 分区方案：MBR（`FDisk_partition_scheme`）
- 卷名：`Bavi-box`
- 卷 UUID：`9CEEA98C-5448-3E71-B488-4805C6FD4B45`

执行前通过 `diskutil list physical` 确认 `/dev/disk0` 为 1.0 TB 内置物理盘，`/dev/disk4` 为 15.7 GB 外置物理盘。格式化命令仅指向 `/dev/disk4`：

```text
diskutil eraseDisk ExFAT Bavi-box MBRFormat /dev/disk4
```

## 写入与重挂载

- 写入 256 MiB 测试文件，`conv=fsync`，记录吞吐约 11.1 MB/s。
- 复制到中文及空格路径：`.uclaw-media-acceptance/中文 空格路径/层级-01/副本.bin`。
- 执行 `sync`，再执行 `diskutil unmountDisk /dev/disk4` 和 `diskutil mountDisk /dev/disk4`。
- 重挂载后两份文件 SHA-256 一致：

```text
a6d72ac7690f53be6ae46ba88506bd97302a093f7108472bd9efc3cefda06484  write-test-256MiB.bin
a6d72ac7690f53be6ae46ba88506bd97302a093f7108472bd9efc3cefda06484  中文 空格路径/层级-01/副本.bin
```

## 文件系统检查

```text
diskutil verifyVolume /dev/disk4s1
Performing fsck_exfat -n -x /dev/rdisk4s1
The volume Bavi-box appears to be OK
File system check exit code is 0
```

两份 256 MiB 临时测试文件已删除。随后执行 `diskutil eject /dev/disk4`，结果为 `Disk /dev/disk4 ejected`。设备已进入可安全拔出状态。

## 人工重插

用户在安全弹出后确认已人工拔出并重新插入。重新盘点结果：

- 设备重新识别为外置物理 USB `/dev/disk4`，容量仍为 15.7 GB。
- 分区方案仍为 MBR，卷仍为 ExFAT `Bavi-box`。
- 自动挂载点为 `/Volumes/Bavi-box`。
- 卷 UUID 仍为 `9CEEA98C-5448-3E71-B488-4805C6FD4B45`，与格式化及软件重挂载阶段一致。
- 临时大文件已清理；中文及空格目录层级仍可读取。
- 重插后再次执行 `diskutil verifyVolume /dev/disk4s1`，`fsck_exfat` exit code 0，卷 `appears to be OK`。
