## 安全与隔离结论

- activation-only 路径不启动 OpenClaw Gateway，不暴露工作区或普通 IPC。
- Desktop 首激活与 Launcher gate 共用 startup license 公钥集合。
- activation endpoint 由 Launcher 构建配置注入，继承的 `UCLAW_ACTIVATION_*` 被清理。
- release feed 固定 `updates.u-claw.org`；release/runtime、startup license、status、Token 信任材料保持隔离。
- 仓库证据不含完整激活码、Token、startup secret 或设备指纹。

## 结论

本地实现和 fixture 门禁支持继续正式验收，但发布门禁未关闭。全量 `npm test` 有 2 条非 activation 失败，且 Win10/11、普通用户、Defender、正式发行物和物理 U 盘均无真实证据。权威状态保持 `not-release-ready`。
