# WX-10 / WX-12 个人微信真机验收清单

状态：`needs-input`。本清单和 PowerShell 收集器不宣称真实通过；`code`、`mock`、`localhost`、fixture、单元测试均不计入完成。

## 真实环境门禁

- [ ] Win10 x64 普通用户；Defender Antivirus 与 Real-time protection 均开启；系统 PATH 无本机 `node`/`npm`（Bavi-box 随包 Node 可用）。
- [ ] Win11 x64 使用另一台机器；同一物理 U 盘，允许盘符变化；不得用虚拟盘、固定盘或 CI runner 代替。
- [ ] 发布包含 `Bavi-box.exe`、`.uclaw/runtime.pkg`、`.uclaw/version.json`、锁定且可修复的微信插件；`data/.openclaw` 在 U 盘。
- [ ] 普通手机微信、可收发测试消息的单独联系人/群；真实腾讯 iLink 服务；真实 OpenClaw Gateway。Token、账号 ID、二维码和消息内容只写脱敏摘要或 SHA-256。

## 执行顺序与证据

1. 在 U 盘创建证据目录（不要放 token）：`mkdir E:\wx-evidence`。运行 `portable-data-audit.ps1 -ReleaseRoot E:\Bavi-box -EvidencePath E:\wx-evidence\baseline.json -BaselinePath E:\wx-evidence\host-baseline.json -CaptureBaseline`。
2. 运行 `wechat-real-acceptance.ps1 -ReleaseRoot E:\Bavi-box -EvidencePath E:\wx-evidence\wx-a.json -MachineRole machine-a -CaseEvidencePath ...`。缺文件会保持 `needs-input`。
3. 启动连接页：记录“检查中 → 等待扫码 → 已扫码，等待手机确认 → 已连接”。“已连接”必须来自真实 Gateway 权威 `channels.status`，不是 UI/mock。
4. 手机微信扫码并点击确认。记录腾讯 iLink 返回的脱敏 account 摘要、二维码 generation/时间，不记录二维码内容。
5. 发送一条唯一文本入站（例如 `WX-A-<随机短语>`），确认真实 Agent 收到并在同一 peer 回复；记录消息 ID/时间的哈希。再由 Agent 发出唯一文本，确认手机原会话可见。第二个 peer 做隔离检查。
6. 删除/篡改插件 manifest 或 runtime 副本后重启：必须显示“组件损坏，需修复或更新 Bavi-box”；使用签名本地 runtime 修复，再次从 Gateway 读回 `connected`。不接受手工 `npm install`。
7. 正常退出并二启：凭据有效时自动恢复且不重复扫码。短暂停止 Gateway/断网后点击重连；授权失效时必须进入“授权失效，需重新扫码”，旧凭据不能伪报 connected。
8. “退出登录”：停止通道，清理 U 盘 `data/.openclaw/openclaw-weixin/accounts.json` 与 `accounts/`，读回确认为空；重启仍为未连接。不得清理未标记的腾讯/微信目录。
9. 运行中安全拔出 U 盘：停止新写入并提示；重新插入、换盘符后恢复/明确要求重扫。退出、拔盘、卸载后运行 `portable-data-audit.ps1` 和 `wechat-host-residue.ps1`；宿主机只允许带 `.uclaw-residue-owner.json` 的可重建 cache，拒绝未知、账号、token、二维码、消息内容。
10. Win11 机器重复上述必要步骤，合并两份 JSON；任何一项 `blocked`/`needs-input` 都不能标记 WX-12 完成。

## 证据分类规则

每个 case JSON 必须含 `evidenceClass`：`real-windows`、`real-usb`、`real-gateway`、`real-tencent-ilink` 或 `real-phone`。证据包必须能指向截图/日志/哈希文件，但不能包含秘密。`code`、`mock`、`localhost`、`fixture` 只能作为开发参考，必须单独标注且永远不计入通过。

## 当前缺口

本工作树没有真实 Windows、物理 U 盘、普通手机微信、腾讯 iLink 账号或可审计的真实 Gateway；因此当前结论只能是 `needs-input` / `completed-with-blockers`，不能伪造 WX-10/WX-12 通过。
