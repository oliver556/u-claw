# U-Claw 便携版生命周期边界冻结草案

- 日期：2026-08-27
- 文档类型：跨规格边界 / 冻结草案
- 状态：待冻结
- 适用范围：Win/Mac 原生 Launcher、便携版打包、U 盘部署、远程强制更新

## 1. 目标

把三条开发线的边界统一：

```text
Win/Mac 启动修复
远程强制硬更新
打包策略 / streamer key
```

避免三者同时改生命周期后互相覆盖。

## 1.1 2026-08-27 冻结决策

```text
视频 provider 走公网 adapter，不走本机 127.0.0.1 adapter。
当前生产先保留旧公网 adapter：https://video-adapter.gmnlee.com/xai/v1。
服务器和 yiyong.me 路由配置完成后，再切到 https://yiyong.me/uclaw/video/xai/v1。
公网 adapter 首选香港网络优化机承载。
阿里云 1C1G3M 做 license/device/token/发布控制，不承载视频主链路。
旧主播盘 key 不做手动修复工具。
新盘 key 由激活链路写入 data。
强制更新严格无网阻断。
生产入口固定为 https://yiyong.me/uclaw/releases/production.json。
```

## 2. 唯一生命周期

便携版只认这一条生命周期：

```text
用户双击原生 Launcher
-> Launcher 单实例锁
-> Launcher 检查/复制/解压/同步/更新
-> 本机 app cache
-> Electron App 隐藏启动
-> Gateway / Config Server / video adapter ready
-> App ready
-> 显示主界面
-> 用户关闭或更新关闭
-> App 关闭进度
-> 停本次拉起服务
-> runtime data cache final sync -> USB data
-> Shutdown complete
-> 退出
```

禁止再引入第二套生命周期：

```text
Electron 先显示空白窗再做复制/解压
直接从 U 盘运行 App
更新时切换 app/current/
全局按进程名杀服务
普通部署覆盖 data/
远程更新修改 key
```

## 3. 目录边界

程序层：

```text
<USB>/U-Claw/app/
<USB>/U-Claw/U-Claw Launcher.exe
<USB>/U-Claw/U-Claw Launcher.app
<USB>/U-Claw/Mac-Start-App.command
<USB>/U-Claw/Windows-Start-App.bat
<USB>/U-Claw/UCLAW-PACKAGE-NOTES.txt
```

用户数据层：

```text
<USB>/U-Claw/data/
<USB>/U-Claw/data/.openclaw/openclaw.json
<USB>/U-Claw/data/.openclaw/agents/
<USB>/U-Claw/data/logs/
<USB>/U-Claw/data/memory/
<USB>/U-Claw/data/license/
```

本机缓存层：

```text
macOS: ~/Library/Caches/U-Claw/
Windows: %LOCALAPPDATA%\U-Claw\
```

硬规则：

```text
程序层可替换。
用户数据层不可覆盖、不可删除、不可重建。
本机 app cache 可删除重建。
本机 data cache 不可当唯一副本。
```

## 4. 职责边界

### Launcher

负责：

```text
单实例锁
原生进度窗
复制 / 解压 / 同步进度
远程更新检查
下载 / 验签 / staging
启动 Electron App
等待 Gateway ready / App ready
关闭确认
触发 App 受控关闭
```

不负责：

```text
直接修改 openclaw.json
修复 streamer key
启动 Gateway 内部逻辑
杀全局进程名
覆盖 data/
```

### Electron App

负责：

```text
隐藏启动直到 App ready
启动 Gateway / Config Server / video adapter
记录 run-state
普通关闭确认后的关闭进度
更新关闭时跳过确认
停本次拉起服务
final sync
写 Shutdown complete
```

不负责：

```text
下载远程更新包
替换自身程序文件
覆盖 USB data/
迁移 streamer key
```

### Updater

负责：

```text
等待 App/Launcher 退出
必要时按 run-state pid 强杀本次拉起服务
替换程序层
写 version.json
失效本机 app cache stamp
重启 Launcher
```

不负责：

```text
网络下载
生成包
改 data/
改 openclaw.json
改 auth_profile_store
启动 Gateway
直接启动 Electron App
```

### 打包脚本

负责：

```text
构建 Win/Mac app archive
构建 Win/Mac 原生 Launcher
生成 stage
新盘初始化 data/
旧盘部署 data preserved
验证 archive hash
验证 edition key 状态
```

不负责：

```text
旧盘普通部署时修复 key
远程更新包携带 data/
绕过正式 rebuild
把缓存目录当源码
```

## 5. 数据同步边界

启动前：

```text
USB data -> 本机 runtime data cache
```

运行中：

```text
OpenClaw 只读写本机 runtime data cache
```

退出时：

```text
本机 runtime data cache -> USB data
```

同步规则：

```text
openclaw.json 不得被 runtime sync 覆盖成空 key。
普通部署不得覆盖 USB data/openclaw.json。
远程更新不得包含 USB data/openclaw.json。
旧盘 openclaw.json hash 在部署/更新前后必须一致。
```

## 6. Key 边界

Phase 1：

```text
客户版：key 为空，用户后续配置。
主播版新盘：激活链路写入 key。
主播版旧盘：保留旧盘 key 状态。
远程硬更新：不含 key，不改 key。
本轮不提供旧盘 key 手动修复工具。
```

Phase 2：

```text
license/device -> 阿里云 -> 短期 token
```

Phase 2 未冻结前，禁止把短期 token 逻辑混入 Phase 1。

## 7. 三条 worktree 边界

建议：

```text
codex/win-launcher-hotfix
  只修 Win/Mac 原生 Launcher 启动、关闭、进程生命周期。

codex/hard-update
  只做远程强制更新、updater、签名、事务、更新关闭协议。

codex/package-policy
  只做打包策略、key 初始化/保留验证、发布包生成评估。
```

禁止同一分支同时改：

```text
Launcher 生命周期 + hard update installer + streamer key 修复
```

若必须碰同一文件：

```text
先冻结职责边界。
先合并生命周期修复。
再在 hard-update 分支接入更新协议。
最后在 package-policy 分支补打包产物规则。
```

## 8. 已冻结问题

P0 冻结：

```text
视频 provider 写公网 adapter。
当前先保留旧公网 adapter；yiyong.me 路由完成后再切换。
主播旧盘 key 缺失本轮不提供手动修复工具。
远程 hard update 首版严格阻断无网络。
生产入口固定为 https://yiyong.me/uclaw/releases/production.json。
```

